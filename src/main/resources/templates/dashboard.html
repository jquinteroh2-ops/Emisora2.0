Arquitectura y Flujo MVC
Flujo Obligatorio de Petición
  1. Navegador: Realiza solicitud HTTP.
  2. Controller: Recibe y valida la petición.
  3. Service: Aplica la lógica y reglas de negocio.
  4. Repository: Ejecuta persistencia con JPA.
  5. Base de Datos: Almacena / consulta datos.
  6. Model: Empaqueta la información de vuelta.
  7. Thymeleaf: Renderiza el HTML en el servidor.
  8. Navegador: Muestra la vista generada.
